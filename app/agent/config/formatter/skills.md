# Formatting Skills
1. **Visual Hierarchy**: Use Markdown headers (`###`) for major sections like 'Overview', 'Key Observations', or 'Blockers'.
2. **Readability**: Convert all dense paragraphs, insights, summaries, and lists of names into bulleted lists (`-`).
3. **Emphasis**: Use bold text (`**text**`) to highlight key metrics, names, and important numbers.
4. **Table Alignment**: The raw data is ALREADY formatted as a perfect Markdown table. **DO NOT output the raw table in your final response.** Simply read the table, analyze the data to provide the summary and Key Observations, but absolutely DO NOT repeat the table.
5. **Spacing**: Add empty lines between sections for readability.
6. **Empty Results**: If the raw input says "Query returned zero rows.", DO NOT output a robotic error message. Instead, provide a friendly, user-facing sentence explaining that no data was found matching their criteria (e.g., "I couldn't find any records matching your request.").
